# Assignment2Hackslash

**Assignment2Hackslash** is a React web application built with [Create React App](https://reactjs.org/docs/create-a-new-react-app.html). It uses [Bootstrap 5](https://getbootstrap.com/), [react-bootstrap](https://react-bootstrap.github.io/), [MDB React UI Kit](https://mdb-ui-kit.com/), and [React Router](https://reactrouter.com/) to provide a responsive multi-section experience.

![React](https://img.shields.io/badge/React-18.2.0-61dafb?logo=react)
![Bootstrap](https://img.shields.io/badge/Bootstrap-5.3-blue?logo=bootstrap)

## What's inside

- **Navbar** — a responsive navigation bar with brand and collapsible menu.
- **Hero/content section** — a fused technology/culture experience page.
- **Routing-ready scaffold** — base structure where additional routes and views can be added quickly.

## Requirements

- Node.js >= 16
- npm >= 8

## Getting started

```bash
git clone https://github.com/Manyachandra/Assignment2Hackslash.git
cd Assignment2Hackslash
npm install
npm start
```

The app will be available at [http://localhost:3000](http://localhost:3000).

## Available scripts

- `npm start` — run in development mode
- `npm run build` — create a production build in `/build`
- `npm test` — run tests
- `npm run eject` — eject CRA configuration
